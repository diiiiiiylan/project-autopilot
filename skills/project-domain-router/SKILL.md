# Project Domain Router

Classify the project domain before choosing expert Skills or agents.

## Domains

- Web/frontend/backend/full-stack
- Mobile/iOS/Android/Expo
- Game/3D/interactive media
- Data/analytics/reporting
- AI/ML/agents/RAG
- Operations/devops/cloud/release
- Security/privacy/supply chain
- Writing/research/documentation
- Design/video/creative production

## Output

Return domain, confidence, relevant installed Skills, missing expert capability, and whether `$project-expert-selection` must run. Do not create or download new Skills from this step.
