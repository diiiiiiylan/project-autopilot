# Project Nuwa Distillation

Use Nuwa only as an approved external dependency for expert method distillation.

## Permission First

As soon as Nuwa becomes necessary or materially beneficial, pause and ask for approval before continuing into the Nuwa branch. State capability gained, fallback if skipped, source URL, install path, network/account/cost needs, and rollback. Do not wait until final reporting.

## Distillation Criteria

- The expert method must be relevant to the project domain.
- Inputs, steps, outputs, and acceptance criteria must be standardizable.
- The resulting Skill must remove private paths, accounts, secrets, and project-only facts.
- Include positive triggers, negative triggers, and failure scenario tests.

If permission is denied or unavailable, create only a local proposal and use the best installed Skill fallback.
