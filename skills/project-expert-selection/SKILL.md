# Project Expert Selection

Select an expert path without duplicating existing Skills.

## Order

1. Check installed Skills and custom agents for a domain match.
2. Check registered open-source Skill sources for a maintained candidate.
3. If no suitable candidate exists, prepare a Nuwa distillation permission request.
4. Explain what is lost if no expert Skill is installed.

Do not download, install, or invoke external expert packages automatically. Route distillation requests to `$project-nuwa-distillation`.
