# Skill Extraction

Create a candidate Skill only when a similar workflow has succeeded at least twice and the inputs, steps, outputs, and acceptance conditions can be standardized.

Before creating a Skill:

- Check existing Skills for overlap.
- Remove private paths, account identifiers, secrets, and project-only details.
- Include positive trigger examples, negative trigger examples, and failure scenario tests.
- Avoid one-off tasks, failed workflows, unverified methods, or highly project-specific content.
