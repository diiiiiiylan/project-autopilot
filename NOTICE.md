# Notices

This repository tracks optional external Skill and MCP sources but does not vendor, download, install, or enable them by default.

- Superpowers: optional methodology Skill pack; keep its upstream license notice if vendored later.
- Karpathy-style Skills: optional local method layer when installed by the user.
- Nuwa Skill: vendored source snapshot for expert-method distillation after explicit user permission; invocation still requires an approved workflow.
- Darwin Skill: vendored source snapshot for Skill evolution experiments after explicit user permission; invocation still requires an approved workflow.
- MCP registries and servers: discovery sources only; installation, enablement, creation, and account-backed tool usage require explicit user permission.
